🌐 Module 2: Networking Basics

Networking is the foundation of modern communication systems. Every website, email, cloud platform, and cybersecurity tool depends on networking principles. Understanding networking is essential before moving into advanced cybersecurity topics.

A computer network is a group of interconnected devices that communicate and share resources such as files, printers, and internet access.

Types of Networks

  • LAN: Local Area Network (office, school)
  • WAN: Wide Area Network (the Internet)
  • MAN: Metropolitan Area Network (city-wide)
  • PAN: Personal Area Network (Bluetooth)

How Data Travels

When you send data, it is broken into small units called packets. Each packet contains:

  • Source IP address
  • Destination IP address
  • Protocol information
  • Actual data

📘 2.2 IP Addressing & Subnetting

An IP address uniquely identifies a device on a network. 

Example:
192.168.1.10

Private IP Ranges

  • 10.0.0.0 – 10.255.255.255
  • 172.16.0.0 – 172.31.255.255
  • 192.168.0.0 – 192.168.255.255

Subnet Mask Example

IP: 192.168.1.10
Mask: 255.255.255.0
CIDR: 192.168.1.0/24

Subnetting improves performance, reduces broadcast traffic, and enhances security segmentation.

📘 2.3 Transport Layer (TCP & UDP)

TCP - Transmission Control Protocol

  • Reliable
  • Connection-oriented
  • Uses acknowledgments
  • Ensures data integrity

TCP 3-Way Handshake:

1. SYN
2. SYN-ACK
3. ACK

UDP - User Datagram Protocol

  • Faster
  • No connection setup
  • No delivery guarantee
  • Used for streaming and gaming

Common Ports

  • 80 - HTTP
  • 443 - HTTPS
  • 22 - SSH
  • 53 - DNS
  • 25 - SMTP

📘 2.4 Routing & Switching

Router

A router connects different networks and forwards packets based on IP addresses using a routing table.

Switch

A switch connects devices within the same network using MAC addresses.

Default Gateway

Example:
192.168.1.1

The default gateway allows devices to communicate outside their local network.

📘 2.5 Network Security Basics

Firewall

A firewall filters incoming and outgoing traffic based on predefined security rules.

NAT (Network Address Translation)

NAT converts private IP addresses into public IP addresses, helping conserve public IP space and improve security.

Common Network Threats

  • ARP Spoofing
  • DNS Poisoning
  • Man-in-the-Middle Attacks
  • Packet Sniffing

📘 2.6 Troubleshooting & Commands

Check IP Address

Windows: ipconfig
Linux: ip addr

Test Connectivity

ping google.com

Trace Route

tracert google.com

Check Open Ports

netstat -ano

Structured troubleshooting steps:

  1. Check physical connection
  2. Verify IP configuration
  3. Ping default gateway
  4. Ping external host
  5. Check DNS resolution
  6. Inspect firewall rules
