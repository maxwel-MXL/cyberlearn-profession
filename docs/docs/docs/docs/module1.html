Module 1: Cybersecurity Foundations

Understanding the Core Principles of Cybersecurity

1. Introduction to Cybersecurity

Cybersecurity is the practice of protecting computer systems, networks, applications, and data from unauthorized access, attacks, damage, or disruption. It involves technologies, processes, and policies designed to safeguard digital assets.

In today's digital world, cybersecurity is critical in banking, healthcare, education, government, and personal communication systems.

2. The CIA Triad (Core Security Model)

🔐 Confidentiality

Confidentiality ensures that sensitive information is accessible only to authorized individuals.

  • Encryption protects data from unauthorized reading.
  • Authentication verifies user identity.
  • Access control limits who can view data.

🛡 Integrity

Integrity ensures that information is accurate and has not been tampered with.

  • Hash functions detect changes in files.
  • Digital signatures verify authenticity.
  • Checksums confirm data consistency.

⚙ Availability

Availability ensures systems and data are accessible when needed.

  • Backups prevent permanent data loss.
  • Redundant systems reduce downtime.
  • Disaster recovery planning ensures continuity.

3. Threat, Vulnerability, and Risk

  • Threat: A potential danger (e.g., malware).
  • Vulnerability: A weakness in a system (e.g., weak password).
  • Risk: The probability of a threat exploiting a vulnerability.

Risk can be simplified as: Risk = Threat × Vulnerability × Impact

4. Types of Cybersecurity Professionals

  • Security Engineer
  • Incident Responder
